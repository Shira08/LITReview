#  Movie App
### Project description: This is an django project to post review on book , article and other 

## Installation
1- Clone the application 
```
[https://github.com/OpenClassrooms-Student-Center/OCMovies-API-EN-FR](https://github.com/Shira08/LITReview.git)
```
2- Create an virtual environment and activate it 
```
python<version> -m venv <virtual-environment-name>

Windows
myenv\Scripts\activate

Linux
source myenv/bin/activate
```
3- Install needed package as in requirements.txt
```
pip install -r requirements.txt
```
4- Run the application
```
python3 manage.py runserver
```
5- Make migration
```
python3 manage.py makemigrations
python3 manage.py migrate
```
6- Open 127.0.0.1 to get on login page

> [!Important]
>
> ## Functionalities
>
> * Account creation (Sign up), login, logout  
> * Feed page with all posts and reviews from people you are following, and your own posts — with the ability to edit and delete your own reviews  
> * Post page with the ability to edit and delete your own posts  
> * Subscription page showing all your followers and followings
